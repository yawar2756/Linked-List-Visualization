A QUICK FIELD GUIDE

Three structures. Three rules.

Every pointer operation makes more sense once the shape is clear.

→SINGLY

One direction

10→20→30→NULL

Each node has one `next` pointer. The last node points to `NULL`.

RememberSave the previous node when deleting from the end.
↻CIRCULAR SINGLY

A loop, not a dead end

10→20→30↶

The tail points back to `head`. Traversal must stop when it reaches `head` again.

RememberHandle the one-node loop where `head->next == head`.
⇄DOUBLY

Both directions

10⇄20⇄30

Each node has `prev` and `next`; links must stay consistent in both directions.

RememberWhen reconnecting nodes, update both `next` and `prev` links.
